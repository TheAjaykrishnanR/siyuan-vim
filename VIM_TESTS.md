# Tests

## Movements

1. j,k across all lines, blocks, lists item
2. h,l through a line in any text, block, list item etc
3. shift+a: move to end line and in insert mode
4. shift+i to goto start of line in insert mode
5. shift+h to got start of line in normal mode

## Vim modes

1. NORMAL
2. INSERT
3. VISUAL

## Edits

1. dd delete line
2. yy copy current line
3. Ctrl+Shift+Enter: insert block above container / codeblock
4. Shift+Enter / Ctrl+Enter: insert block below container / codeblock
5. o / O inside code block: insert sub-line inside code block

## Selection

1. Visual blocks

## Cursor

2. Multiple cursors

## Commands

1. "/" Search
2. ":q" Quit/close
