# Tests

## Movements

1. j,k across all lines, blocks, lists item
2. j,k to and from Note Title
3. gg jumps to Note Title
4. h,l through a line in any text, block, list item etc
5. shift+a: move to end line and in insert mode
6. shift+i to goto start of line in insert mode
7. shift+h to got start of line in normal mode

## Vim modes

1. NORMAL
2. INSERT
3. VISUAL

## Edits

1. dd delete line
2. yy copy current line
3. dw / cw in code block (middle of line, last word on line, and 1-line code block)
4. Ctrl+Shift+Enter: insert block above container / codeblock
5. Shift+Enter / Ctrl+Enter: insert block below container / codeblock
6. o / O inside code block: insert sub-line inside code block

## Selection

1. Visual blocks

## Cursor

2. Multiple cursors

## Commands

1. "/" Search
2. ":q" Quit/close
